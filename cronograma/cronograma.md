# Cronograma do projeto (calculadora — TCC)

Documento de referência temporal: organização **semana a semana**, com base no consolidado que você já tinha (intervalos e marcos com data única).  
Não substitui PRD, casos de uso, requisitos nem demais artefatos de engenharia de software — serve só como **linha do tempo** para alinhar entregas físicas, texto do trabalho e material de apresentação.

---

## Como ler este cronograma

- **Semanas:** domingo a sábado, numeradas a partir de **01/03/2026** (domingo).
- **“Em vigência”:** intervalos do plano original que **cruzam** aquela semana (podem continuar nas semanas seguintes).
- **“Marcos (data única)”:** acontecimentos previstos para um dia específico no consolidado.
- **Última data do consolidado:** **25/09/2026** (término previsto da criação do banner). Ajuste o fechamento com a data real da banca ou do curso, se for anterior.
