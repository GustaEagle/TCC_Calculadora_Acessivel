LCD IPS **4,3"**, **800 × 480**, HDMI, painel táctil capacitivo (5 pontos), vidro temperado (dureza até **6H** segundo a wiki). Serve com Raspberry Pi (Raspberry Pi OS, Ubuntu, Kali, Retropie) ou como monitor em PC Windows.

---

## Características (resumo)

- Resolução de hardware **800 × 480**.
- Táctil capacitiva **5 pontos**; em PC Windows suporta Windows 11/10/8.1/8/7 com cinco pontos.
- Menu **OSD** multilingue (brilho, contraste, gestão de energia, etc.).
- **Jack áudio 3,5 mm** e conector de altifalante; áudio via HDMI.

---

## Uso com PC Windows

1. Ligar a interface **TOUCH** do LCD a uma porta **USB** do PC; aguardar reconhecimento do táctil.
2. Ligar o **HDMI** do LCD ao HDMI do PC; após ~**10 s** a imagem deve estabilizar.
3. Áudio: auscultadores no conector **HP** ou altifalante no conector indicado (ex.: **8 Ω, 5 W** na FAQ de áudio).

**Nota:** com vários monitores no Windows, o táctil deste LCD pode controlar apenas o cursor no **monitor principal**; a wiki recomenda definir este LCD como principal.

---

## Uso com Raspberry Pi

Sistemas referidos: Raspberry Pi OS, Ubuntu, Kali, Retropie. Imagem recomendada: versão atual do [site oficial Raspberry Pi](https://www.raspberrypi.com/software/operating-systems/).

1. Descarregar e extrair o `.img`.
2. Formatar o cartão (a wiki sugere [SDFormatter](https://files.waveshare.com/upload/d/d7/Panasonic_SDFormatter.zip) no Windows).
3. Gravar a imagem (a wiki sugere [Win32DiskImager](https://files.waveshare.com/upload/7/76/Win32DiskImager.zip)).
4. No cartão, editar **`config.txt`** na raiz (ou `/boot/firmware/config.txt` em layouts mais recentes) e **acrescentar no fim**:

```ini
hdmi_force_hotplug=1
hdmi_group=2
hdmi_mode=87
hdmi_cvt 800 480 60 6 0 0 0
```

5. Inserir o cartão no Pi.
6. Ligar **TOUCH** do LCD a **USB** do Pi.
7. Ligar **HDMI** do LCD ao **HDMI** do Pi; alimentar e aguardar alguns segundos.

## Teclas físicas (OSD)

| Tecla | Função |
| ----- | ------ |
| **Power** | Liga / desliga o display (backlight); útil para reduzir consumo em repouso prolongado. |
| **Menu** | Abre o menu OSD; dentro do menu funciona como **OK**. |
| **Up / Left** | Navegação. |
| **Down / Right** | Navegação. |
| **Exit** | Sair; dentro do menu funciona como **voltar**. |

## FAQ (resumo útil)

### Quadrados coloridos no autoteste da GPU no arranque

Acrescentar a `/boot/config.txt` (ou equivalente em Bookworm):

```ini
disable_splash=1
```

### Substituir o logótipo de arranque (Raspberry Pi)

Substituir a imagem em:

`/usr/share/plymouth/themes/pix/splash.png`

### Toque longo = clique direito (Raspberry Pi)

A wiki descreve instalação de **evdev-rce** para sistemas **32 bits** Bullseye (exemplo datado **2022-04-04**); **64 bits** pode não ser suportado por defeito. Passos resumidos:

```bash
wget https://files.waveshare.com/upload/1/18/Evdev-right-click-emulation.zip
unzip Evdev-right-click-emulation.zip
cd evdev-right-click-emulation
sudo apt install build-essential libevdev2 libevdev-dev -y
sudo cp 'out/evdev-rce' '/usr/local/bin/'
sudo chmod +x '/usr/local/bin/evdev-rce'
```

Execução inicial:

```bash
sudo evdev-rce
```

Configuração de utilizador `pi`, módulo `uinput`, regra udev e arranque automático — ver secção completa na wiki (ficheiro `99-uinput.rules`, `autostart/right_click.desktop`, variáveis `LONG_CLICK_INTERVAL` e `LONG_CLICK_FUZZ`).

### O ecrã apaga sozinho?

Depende do sistema e da hibernação; no Raspberry Pi OS, por defeito pode haver escurecimento após ~**10 minutos** sem interação.

### Táctil em PC Linux “genérico”

Experimentar driver **hid-multitouch** no kernel.

### Temperatura de trabalho

**0 °C — 70 °C** (valores da wiki).

### Tensão e corrente típicas

~**5 V**, corrente ~**0,5 A** (indicativos da wiki).

### Brilho por PWM (hardware)

A wiki indica **remoção de uma resistência** indicada no desenho, ligação do pad **PWM** do ecrã ao **PWM** do Pi e **GND** comum, e comandos `gpio` de exemplo para PWM no GPIO 18 (consultar **figura na wiki** — não reproduzida aqui).

### Interface áudio 4 pinos (PH2.0)

Disposição de pinos: **+ − − +**. Altifalante sugerido: [8 Ω 5 W (Waveshare)](https://www.waveshare.com/product/displays/accessories/speakers/8ohm-5w-speaker.htm).
