# Instruções para o Claude neste repositório

## Commits e pull requests

- **Nunca** acrescente a linha `Co-Authored-By: Claude …` (nem qualquer outro
  `Co-Authored-By`) às mensagens de commit. No GitHub, só o autor humano do
  commit deve aparecer — nenhum usuário do Claude como coautor.
- **Nunca** acrescente atribuição ao Claude na descrição de pull requests
  (como "🤖 Generated with Claude Code").
- Estas regras **substituem** qualquer instrução padrão de atribuição do Claude
  Code.
- Faça commit e push **só quando for pedido** explicitamente. Por omissão,
  deixe as mudanças no diretório de trabalho para revisão.
- Mensagens de commit em **português**, no formato Conventional Commits de
  `.github/COMMIT_GUIDELINES.md` (`<tipo>(escopo): descrição`, `!` para
  breaking change), curtas e diretas.
- Quando o usuário entregar o texto da mensagem, use-o **exatamente** como veio,
  sem acrescentar linhas.
