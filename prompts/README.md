# Prompts do repositório (TCC Calculadora)

Arquivos de texto para colar em conversas com IA (ex.: Cursor) e padronizar rituais da equipe.

| Arquivo | Quando usar |
| ------- | ----------- |
| [`bootstrap.txt`](bootstrap.txt) | **Início de sessão:** Git atualizado, branch correta, leitura de contexto antes de codar. |
| [`close-session.txt`](close-session.txt) | **Fim de sessão:** resumo, `Sprints.md`, `docs/CONTEXT.md`, handoff. |
| [`agent-sprint-coach.txt`](agent-sprint-coach.txt) | **Durante a sessão:** saúde do sprint atual vs PRD e cronograma. |
| [`agent-weekly-squad-lead.txt`](agent-weekly-squad-lead.txt) | **Semanal:** retrospectiva, status do projeto, prioridades da próxima semana (papel tech/squad lead). |
| [`agent-github-sync.txt`](agent-github-sync.txt) | **Equipe / Git:** checar se a branch está atrás de `main`, explicar fluxo Gustavo → João e merge paralelo. |

Fluxo Git e convenções: [`docs/GITHUB_WORKFLOW.md`](../docs/GITHUB_WORKFLOW.md).  
Commits: [`.github/COMMIT_GUIDELINES.md`](../.github/COMMIT_GUIDELINES.md).
