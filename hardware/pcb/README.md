# PCB — KiCad

Coloque aqui o **projeto principal** (ex.: `tcc-calculadora/` com `.kicad_pro`).

## Snapshots (marcos)

Exportações conscientes (não substituem o Git do projeto):

```
snapshots/
  2026-05-01-pre-banca/
  2026-06-10-entrega/
```

Cada pasta pode conter: Gerber ZIP, PDF do esquemático, lista de materiais, notas de revisão.

## O que não versionar

A pasta **`.history/`** gerada pelo KiCad fica fora do Git (ver `.gitignore` na raiz).
